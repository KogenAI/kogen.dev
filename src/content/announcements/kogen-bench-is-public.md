We want to make decisions by numbers. We’re not attached to our hypotheses. If I think an agent needs a better plan or more context, I can try that on the same job and see what happens. Is it getting the work done? How long does it take? How much of what it did did it actually need to do?

That's the work I’ve been doing while building [Kogen](https://kogen.dev). We've been trying different models, plans and project context. We've also been looking at the checks we can give agents and what they do when those checks fail. Sometimes a failure tells me what to try next. Sometimes I’m done with an approach and I want to move on.

Anyway, the site is live. I want all the benchmark information on [Kogen Bench](https://bench.kogen.dev). If you want to try the same run, the instructions will be there with the method and results. We’ll put the updates there as we test more tasks and decide what we want to build into Kogen. There’s still plenty of exploratory work here.

[Explore Kogen Bench](https://bench.kogen.dev).
