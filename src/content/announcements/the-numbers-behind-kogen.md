Building [Kogen](https://kogen.dev) has meant testing a lot of ideas about how software-building agents should work. I’m opening [Kogen Bench](https://bench.kogen.dev) to share that work as it develops.

We’ve been comparing models, planning approaches, project context, and ways to check and improve the software they produce. The questions are practical: what helps an agent finish a task correctly, how long does it take, and how much work does it waste along the way?

The process is simple: try something, measure what happens, and use what we learn to choose the next experiment. Sometimes that means improving an approach. Sometimes it means dropping it.

Bench will be the home for all of Kogen’s benchmark information: the experiments, results, methods, and instructions for running them. As the work develops, the details and updates will live there.

This is far from final. Much of the work so far is exploratory, and there are plenty of questions left to answer. Next comes testing ideas on a wider range of tasks, understanding failures better, and using those lessons to build Kogen.

The real work starts here.
